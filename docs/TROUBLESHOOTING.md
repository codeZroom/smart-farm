# 장애 대응

| 증상                           | 확인 및 조치                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------- |
| Supabase 연결 안내 화면        | apps/web/.env.local의 URL/공개 키, 서버 재시작                               |
| 로그인 401                     | Auth 계정/비밀번호/이메일 확인 상태, 사용자 로그인 제한                      |
| 변경 요청 403                  | 주소창 origin과 APP_ORIGIN의 프로토콜/호스트/포트 일치 여부                  |
| 장치 401                       | UUID·활성 여부·현재 키 확인, 키 재발급 후 이전 키는 사용 불가                |
| 장치 422                       | UUID, 숫자 타입, 온도 -40~125, 습도 0~100, 센서 실패 계약                    |
| 장치 429                       | 같은 장치로 두 송신기가 동작하는지 확인, 30초 주기로 통일                    |
| 수집 503                       | 서버 service_role 설정, migration 적용, DB 연결/함수 권한 확인               |
| 값은 있는데 그래프가 비어 있음 | 선택 장치와 기간, 서버 수신시각, 조회 사용자 소유권 확인                     |
| 오프라인 표시만 있고 알림 없음 | 스케줄러 미등록/CRON_SECRET 오류/최근 100건 제한 확인                        |
| 비활성 장치                    | 활성화하고 키가 폐기되지 않았는지 확인                                       |
| Docker pipe 없음               | Docker Desktop Linux 엔진 시작 후 docker info                                |
| npm DNS 실패                   | 네트워크/프록시/registry 접근 확인 후 npm ci                                 |
| PWA 설치 버튼 없음             | HTTPS, manifest/SW, 브라우저 지원, 이미 설치 여부 확인                       |
| Wi-Fi 연결 실패                | 2.4GHz SSID, 비밀번호, 전원, 신호, captive portal 없는 망 확인               |
| HTTPS 실패                     | NTP 동기화, API 호스트와 ROOT_CA의 체인, CA 갱신 여부 확인. 검증을 끄지 않음 |
| 센서 실패                      | 3.3V/GND, SDA21/SCL22, I²C 주소 0x44, 접촉/결로 확인                         |

새 키나 서비스 키를 오류 보고서·스크린샷·Serial 로그에 포함하지 마세요. 보고 시 HTTP 상태, 펌웨어 버전, 수신 시각, 익명화한 장치 ID를 사용하세요. DB 백업을 확보하기 전에 reset/DROP을 실행하지 마세요.
